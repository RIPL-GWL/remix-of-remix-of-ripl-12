# Media library

Optimized WebP backup copies (max 1920px, quality 76–80) of every image the website uses. The live site loads images from CDN pointers in src/; these files are a full offline copy kept in the repo.

Latest refresh: all 136 website images re-downloaded, normalized to PNG (max 1920px wide), then re-optimized to WebP (quality 80). Older extra backups are kept.
