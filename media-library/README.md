# Media library

Optimized WebP backup copies (max 1920px, quality 76–80) of every image the website uses. The live site loads images from CDN pointers in src/; these files are a full offline copy kept in the repo.

Latest audit: 152 valid images, approximately 13.08 MiB. The latest optimization reduced 22 larger backup images and refreshed 14 corresponding website assets without changing their import paths or subjects.
